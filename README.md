# Gestión Escuela

Plataforma web para gestión de academias: cursos, ediciones, alumnos, inscripciones y diplomas PDF.

## Stack
- **Backend:** Node.js + Express + Sequelize + SQLite
- **Frontend:** React + Vite + TailwindCSS

## Quick Start

### Backend
```bash
cd backend
cp .env.example .env
npm install
npm run dev
```

### Frontend
```bash
cd frontend
npm install
npm run dev
```
